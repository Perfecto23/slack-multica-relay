# 七项决策卡

每张卡属于一个真实问题任务，保留 cardVersion。未知项写具体缺口与已查内容。

1. **问题与来源**：用户目标、实际来源与当前任务链接。
2. **用户背景**：用户类型、场景、影响；多类用户的诉求分别描述。
3. **现状与依据**：已核实行为、有效决定、证据与缺口。
4. **本次决定**：一个具体选择及影响边界。
5. **选项**：2–3 个实质不同方案，说明用户收益、代价与风险。
6. **推荐**：推荐与理由、范围、排除项、验收标准、现有实现参照，以及会改变推荐的前提。
7. **真人决定**：决策人对当前版本的选择、原因、范围、验收及必要设计材料；记录原评论与 decisionVersion。

已有明确推荐但需要真人确认的标题用“待确认”；存在真实产品取舍的用“待取舍”。“同意推荐”仅在第 6 项边界完整且作者有权决定时采用。暂缓/不做保留原因和再评估条件；建议维持建议状态，真实决定才写入决定记录。
